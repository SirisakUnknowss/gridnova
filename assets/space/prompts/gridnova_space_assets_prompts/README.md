# GridNova — Light Space Theme Asset Prompt Pack

ชุด Prompt สำหรับสร้าง Asset และ Background ของ GridNova Sudoku
แนวทางหลัก: **Light Space / Clean / Focus-first / Soft 3D / Pastel Sci-fi**

## เป้าหมาย
- ใช้กับหน้าเกม Sudoku โดยไม่แย่งสายตาจากกระดาน
- Background ต้องเบลอ/สะอาด/contrast ต่ำ
- Asset เป็น 3D soft plastic / glossy / premium mobile game
- หลีกเลี่ยง dark mode, neon cyberpunk, background ที่รายละเอียดแน่น
- ใช้โทนสี: white, ice blue, lavender, periwinkle, soft peach, pale gold
- ตัวละครและวัตถุควรอ่านง่ายแม้ย่อขนาด

## Recommended generation
- Background: 9:16, 1440×2560 หรือ 1536×2732
- Card/hero illustration: 4:5 หรือ 1:1
- Isolated asset: 1:1, transparent background
- Icon: 1:1, transparent background
- Decorative planet: 1:1, transparent background

## Global style keywords
`clean light space aesthetic, pastel sci-fi, premium casual mobile game, soft 3D,
glossy white plastic, lavender accents, icy blue highlights, subtle ambient occlusion,
rounded forms, soft daylight, low visual noise, elegant, friendly, polished`

## Global negative prompt
`dark mode, black background, cyberpunk, aggressive neon, horror, gritty texture,
high contrast, cluttered background, dense stars, too many planets, photorealistic astronaut,
complex machinery, excessive reflections, text, logos, watermark, UI screenshot,
sharp metallic surfaces, red dominant palette`

ไฟล์แต่ละ prompt ถูกแยกตามหมวดเพื่อเอาไป generate ทีละ asset ได้ง่าย
