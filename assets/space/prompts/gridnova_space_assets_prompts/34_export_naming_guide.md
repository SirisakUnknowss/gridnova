# Export Naming Guide

- `bg_home_space_light.webp`
- `bg_menu_blur.webp`
- `bg_difficulty.webp`
- `bg_book_mode.webp`
- `bg_splash.webp`

## Gameplay State
- `cell_selected.png`
- `cell_hint.png`
- `cell_error.png`

## Meta
- `asset_trophy.png`
- `asset_streak.png`
- `asset_hint.png`
- `asset_loading.png`
- `asset_empty_state.png`

## Recommended formats
- Background: WebP
- Transparent illustration: PNG/WebP alpha
- Simple vector icon: SVG
- Figma icons: convert to vector where possible
