# Facebook post — GridNova 2.1.0

🎉 GridNova 2.1.0 มาแล้ว!

ตามคำขอของผู้เล่นหลายคน เรานำหน้าตาเกมแบบดั้งเดิมกลับมาในชื่อ **GridNova V1** 💜

ธีมนี้ออกแบบมาให้เรียบง่าย สบายตา และช่วยให้มีสมาธิกับการเล่น Sudoku มากขึ้น โดยสามารถเลือกใช้งานได้ฟรีจากหน้า Shop

อัปเดตครั้งนี้ยังเพิ่มคีย์ลัดสำหรับผู้เล่นบนคอมพิวเตอร์:

⌨️ `Z` — Undo
⌨️ `Y` — Redo
⌨️ `E` — Erase
⌨️ `N` — เปิด/ปิด Notes
⌨️ `H` — Hint
⌨️ `Esc` — Menu

พร้อมปรับปรุงการแสดงผลกระดานและแถบเครื่องมือให้พอดีกับหน้าจอมากขึ้น รวมถึงแก้สีและเส้นตารางของ GridNova V1 ให้กลับมาใกล้เคียงหน้าตาดั้งเดิม

ขอบคุณทุกคำแนะนำจากผู้เล่นนะครับ ฟีดแบคของทุกคนช่วยให้ GridNova ดีขึ้นจริง ๆ 🙏

เล่นได้ที่: https://gridnova.pages.dev
