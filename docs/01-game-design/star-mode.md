## 🎯 ทำไมต้องมี

ฟีดแบ็กจากผู้เล่น: เกม Sudoku/Nonogram หน้าตาเรียบๆ ในตลาดมีเยอะแล้ว
GridNova ต้องมี **เป้าหมายนอกเหนือจากการแก้ปริศนา** เพื่อสร้างความแตกต่างและเหตุผลให้กลับมาเล่น

แนวทาง: เอา **กลไก** ของเกมแนว renovation (match-3 + แต่งบ้าน) มาใช้กับ Sudoku
— ชนะ → ได้ดาว → ใช้ดาวทำงานปรับปรุงบ้านทีละขั้น → เห็นภาพ ก่อน/หลัง

เอกลักษณ์ของเรา: **เรือนไทย + แมวไทย** (Siamese / Khao Manee / Korat / Suphalak)
ใช้แค่กลไกของแนวเกม — ภาพ ตัวละคร และฉากต้องเป็นของเราเองทั้งหมด

## 🚫 Non-goals (MVP)

- ไม่มีเนื้อเรื่อง/บทพูดยาว
- ไม่มีการลากวางของอิสระ (free placement)
- ไม่ขายดาวด้วยเงินจริงหรือเหรียญ
- ไม่แตะ Daily / Time Attack leaderboard
- มีพื้นที่เดียวก่อน (ห้องนั่งเล่น) — พื้นที่ที่สองค่อยทำเมื่อ metric ผ่าน

## 🔁 Core Loop

```
เลือกระดับ → ใช้ 1 ❤️ → แก้ Sudoku → ชนะ → ได้ ⭐ (+ คืน ❤️)
                                              ↓
                       ใช้ ⭐ ทำงานถัดไปในบ้าน → เลือก 1 ใน 3 สไตล์ → ภาพเปลี่ยน + แมวมีปฏิกิริยา
```

## 🎮 กติกาโหมด

### ระดับความยาก
ใช้ **4 ระดับ** (ไม่ใช่ 7 แบบ Practice) — เลือกง่าย ตัดสินใจเร็ว

| Difficulty | ⭐ ต่อการชนะ | เวลาโดยประมาณ* |
|---|---|---|
| easy | 2 | ~3 นาที |
| medium | 3 | ~5 นาที |
| hard | 4 | ~10 นาที |
| expert | 5 | ~18 นาที |

**Flawless bonus:** ไม่ผิดเลย + ไม่ใช้ hint → **+1 ⭐**

\* อ้างอิงจาก `TIME_ATTACK_TIERS`; expert เป็นค่าเดา — **ต้องดึงเวลาจริงจาก
`user_game_history` ก่อน finalize ตัวเลข**

### ทำไมระยะห่างของดาวแคบ (2→5) แต่ยังไม่ทำให้ทุกคน farm easy

ถ้าวัดเป็น **ดาวต่อนาที** easy คุ้มกว่า expert ~2.4 เท่า
แต่โหมดนี้เป็น **gated (ใช้หัวใจ)** — สิ่งที่จำกัดผู้เล่นคือ *จำนวนตา* ไม่ใช่เวลา
ผู้เล่นจึงคิดเป็น **ดาวต่อหัวใจ** ซึ่งเล่นระดับยากคุ้มกว่า
(เหมือนเกม renovation ที่มี lives จำกัด)

ความเสี่ยงที่ยังเหลือ: ชนะได้ = คืนหัวใจ คนเก่งจึงเล่นได้ไม่จำกัดอยู่ดี
→ ถ้า playtest พบว่า farm easy จริง ให้ถ่างเป็น **2 / 4 / 7 / 10**

### Hearts
- **Gated** — ใช้ 1 ❤️ ตอนเริ่ม คืนเมื่อชนะ (เหมือน Daily/Random/Time Attack)
- ส่ง `consume_heart('star')` — RPC รับ mode เป็น text อยู่แล้ว ไม่ต้องแก้

### Hints & Continues
เหมือน Practice (ไม่มี leaderboard จึงไม่มีปัญหาความยุติธรรม):
- Free hints ตาม `freeHintsForLevel()` + paid hints 50/75/100 coins
- Continue ใช้เหรียญได้ ราคาตาม `PRACTICE_CONTINUE_BASE`
- ใช้ hint ใดๆ = เสีย flawless bonus

### ดาวจากโหมดอื่น
| Mode | ⭐ |
|---|---|
| Star Mode | ตามตารางข้างบน |
| Daily (ชนะ) | **+1** — คนเล่น Daily อย่างเดียวยังคืบหน้าได้ |
| Practice / Random / Time Attack | 0 (MVP) |

## 🏠 Home Renovation

### พื้นที่แรก: Living Room (เรือนไทย)
- พื้นหลังสภาพ "เก่า/ทรุดโทรม" → ทุกงานเปลี่ยนส่วนหนึ่งให้ใหม่
- **10 งาน** เรียงตามลำดับตายตัว (ปลดล็อกทีละงาน)
- แต่ละงานมี **3 สไตล์** ให้เลือกตอนทำเสร็จ — เปลี่ยนสไตล์ทีหลังได้ฟรี

| # | งาน (ตัวอย่าง) | ⭐ |
|---|---|---|
| 1 | กวาดฝุ่น/ซ่อมพื้นไม้ | 2 |
| 2 | ซ่อมหน้าต่างบานเฟี้ยม | 2 |
| 3 | ปูเสื่อ/พรม | 3 |
| 4 | ตั่ง/ม้านั่ง | 3 |
| 5 | ตะเกียง/โคมไฟ | 3 |
| 6 | ที่นอนแมว | 3 |
| 7 | ตู้ไม้ | 4 |
| 8 | ต้นไม้ในกระถาง | 3 |
| 9 | รูปภาพฝาผนัง | 3 |
| 10 | ม่าน + ไฟประดับ | 4 |
| | **รวม** | **30** |

### Pacing
- เฉลี่ย ~3.5 ⭐/ชนะ → 30 ⭐ ≈ **8–9 ชนะ**
- ผู้เล่นทั่วไปชนะ 2–3 ตา/วัน → **ห้องแรกเสร็จใน 3–5 วัน** (เป้าหมาย)
- เสร็จห้อง → รางวัลก้อนใหญ่ (เหรียญ + แมวตัวใหม่ หรือกรอบ avatar)

### แมวคู่หู
- เริ่มด้วย Siamese 1 ตัว · 3–4 ท่า (นอน / นั่ง / เล่น / ดีใจ)
- ย้ายไปอยู่บนของชิ้นล่าสุดที่เพิ่งทำเสร็จ (เช่น ทำที่นอนแมวเสร็จ → แมวไปนอน)
- แมวตัวใหม่เป็นรางวัลจบห้อง (เป้าหมายระยะยาว)

### พื้นที่สอง: Lotus Garden (สวนบัวริมคลอง)

ปลดล็อกเมื่อทำ Living Room ครบ — ทำต่อเมื่อ metric ของห้องแรกผ่านแล้วเท่านั้น

**งานเป็นแบบ "ซ่อม"** — ภาพ "ก่อน" มีของพังอยู่แล้ว แต่ละงานเปลี่ยนของพังเป็นของใหม่
(ตรงกับแนว renovation มากกว่าการวางของลงพื้นที่ว่าง)

| # | ของพังในภาพ "ก่อน" | งาน | ⭐ | หมายเหตุ |
|---|---|---|---|---|
| 1 | วัชพืช ใบไม้ร่วง | ถางหญ้า | 2 | |
| 2 | ทางเดินหินแตก | ปูทางเดินใหม่ | 3 | 3 สไตล์ |
| 3 | บ่อแห้ง ดินแตก | เติมน้ำ + ปลูกบัว | 4 | 🌱 โต |
| 4 | รั้วหลังพัง | ซ่อมรั้ว | 3 | 3 สไตล์ |
| 5 | สะพานไม้ผุ | สร้างท่าน้ำ | 4 | 3 สไตล์ |
| 6 | ม้านั่งพัง | แคร่ / ม้านั่ง | 4 | แมวออกมานอนตรงนี้ |
| 7 | โอ่งเก่า | ปลูกไม้ดอกในโอ่ง | 3 | 🌱 โต |
| 8 | ลานดินว่าง | ต้นลีลาวดี | 3 | 🌱 โต |
| 9 | ต้นไม้ใหญ่ | แขวนโคม / ชิงช้า | 4 | 3 สไตล์ |
| 10 | มุมริมน้ำ | ศาลาริมน้ำ | 6 | ชิ้นเด่นของพื้นที่ |
| | | **รวม** | **36** | |

**กลไกเฉพาะสวน: ต้นไม้โต**
- ปลูกแล้วโตตามจำนวนชนะ (ทุกโหมด): ต้นอ่อน → พุ่ม → ออกดอก · 2–3 ชนะต่อขั้น
- ผูกกับชนะ ไม่ใช่เวลาจริง — ไม่ต้องมี server clock หรือ push notification
- สวนยังเปลี่ยนต่อหลังทำงานครบ → มีเหตุผลกลับมาดู
- ต้นไม้ **ไม่มีตัวเลือกสไตล์** (1 แบบ × 3 ขั้น) เพื่อคุมจำนวนภาพ

**เชื่อมกับ Season:** บ่อและศาลาเปลี่ยนตามอีเวนต์ (กระทงในบ่อช่วงลอยกระทง ฯลฯ)

**หลีกเลี่ยง:** ศาลพระภูมิ — ของศักดิ์สิทธิ์ ใช้ดาว "ตกแต่ง" อาจไม่เหมาะ

### แผนที่หมู่บ้านริมคลอง (ระยะยาว)

ทุกพื้นที่อยู่บนแผนที่ isometric เดียวกัน · พื้นที่ที่ยังไม่ปลดล็อกคลุมหมอก/เป็นเงา
ให้ผู้เล่นเห็นเป้าหมายระยะยาวตั้งแต่วันแรก

```
            [ทุ่งนา + กระท่อม]      [งานวัด - Season]
                    \                    /
   [สวนผลไม้] —— [เรือนไทยหลัก] —— [สวนบัว + ศาลาริมน้ำ]
                    |
        ~~~~~~~~~ คลอง ~~~~~~~~~ [ตลาดน้ำ + ท่าเรือ]
```

| ลำดับ | พื้นที่ | สถานะ |
|---|---|---|
| 1 | เรือนไทยหลัก (Living Room, ตัดหลังคาเห็นห้องใน) | MVP |
| 2 | สวนบัว + ศาลาริมน้ำ | หลัง metric ผ่าน |
| 3+ | ตลาดน้ำ · สวนผลไม้ · ทุ่งนา | ระยะยาว |
| Season | งานวัด · ลอยกระทง · สงกรานต์ | ผูกกับแท็บ Season |

วางผังทั้งแผนที่ไว้ตั้งแต่ตอนนี้ แม้จะ build ทีละพื้นที่ — เพื่อไม่ต้องรื้อตอนเพิ่ม

## 👤 Guest vs Member

ตามแบบ hearts: guest ไม่มี auth session
- **Guest:** เล่นได้ เก็บดาวและความคืบหน้าบ้านใน `localStorage` (`gn_guest_home_v1`)
- **ตอนสมัคร:** claim ความคืบหน้าขึ้น server (แบบเดียวกับ `guest_game_history`)
- บ้านที่ค้างอยู่เป็น growth hook ที่ดี: "สมัครเพื่อไม่ให้บ้านหาย"

## 🗄️ Data Model (ร่าง)

Migration ใหม่ไฟล์เดียว · ⚠️ staging ใช้ prod DB ร่วม — push `supabase/**` บน staging = ขึ้น prod ทันที

```sql
-- catalog (seed)
home_areas  (id text pk, name, sort_order)
home_tasks  (id text pk, area_id fk, sort_order int, star_cost int, styles text[3])

-- per user
user_stars         (user_id pk, balance int, lifetime int, updated_at)
user_home_progress (user_id, task_id, style text, completed_at, pk(user_id, task_id))
```

**RPCs (SECURITY DEFINER, server-authoritative เหมือน hearts)**
- `award_stars(p_game_id)` — คำนวณดาวจากเกมที่บันทึกแล้วใน `user_game_history`
  (client ไม่ส่งจำนวนดาว) · กันรับซ้ำต่อ game id
- `complete_home_task(p_task_id, p_style)` — เช็คว่าเป็นงานถัดไป + ดาวพอ → หักดาว + บันทึก
- `set_home_style(p_task_id, p_style)` — เปลี่ยนสไตล์ฟรี
- `get_home_state()` — balance + progress
- `claim_guest_home(p_payload)` — ตอนสมัคร · cap ค่าที่รับได้

ดาวเป็นของตกแต่งล้วน → ความเสี่ยงโกงต่ำ แต่ยังคำนวณฝั่ง server

## 🎨 Art Scope (MVP)

| Asset | จำนวน |
|---|---|
| พื้นหลังห้อง ก่อน/หลัง | 2 |
| ของตกแต่ง (10 งาน × 3 สไตล์) | 30 |
| แมว Siamese (ท่าทาง) | 3–4 |
| ไอคอนดาว + UI | ~5 |

**Lotus Garden (พื้นที่สอง):** ภาพ ก่อน/หลัง 2 · งานมีสไตล์ 6 งาน × 3 = 18 ·
ต้นไม้ 3 ต้น × 3 ขั้น = 9 · ถางหญ้า 1 → **~30 ภาพ**

### Style direction
**Isometric การ์ตูน** (แนวเดียวกับเกมแต่งบ้านทั่วไป) — ไม่ใช่ painterly/perspective
- 2:1 isometric · เส้นขอบเข้ม · cel-shaded · สีสด แต่ละโซนมีสีประจำ
- อาคารตัดหลังคาให้เห็นห้องใน
- เหตุผล: มุมคงที่ตามกริด → วางของซ้อนเลเยอร์ง่าย, อ่านออกบนจอมือถือ
- ใช้แค่ convention ของแนวเกม — ห้ามเลียนผัง/อาคาร/ตัวละครของเกมใด

Style block สำหรับ AI:
```text
Isometric mobile game art, true 2:1 isometric projection, bright cheerful cartoon style, clean shapes with soft dark outlines, smooth cel-shaded lighting from upper left, saturated warm colors, each zone with its own distinct color identity, cutaway buildings with no roof showing interior rooms, tiny readable details, cozy and inviting, no text, no UI, no people
```

**ข้อควรระวัง:**
- AI ทำมุม isometric ไม่สม่ำเสมอ → ใช้ทำ concept ได้ แต่ asset จริงต้องเกลามุม/เส้น หรือจ้างทำ base tile
- ห้ามผสมกับสไตล์ painterly (ภาพสวนชุดแรกใช้เป็น mood reference เท่านั้น)
- ภาพ painterly: ทำของแต่ละชิ้นด้วย inpainting บนภาพฐานจะกลมกลืนกว่าตัด PNG มาแปะ
ภาพทั้งหมดใส่ `globIgnores` หรือ lazy-load — ห้ามเพิ่มเข้า precache (ดู CLAUDE.md เรื่อง Pages Function)

## 🧪 Playtest & Metrics

### Phase 0 — ทดสอบก่อนเขียนโค้ด
1. **Mockup 2–3 ทิศทางอาร์ต** (เรือนไทย+แมว / แฟนตาซี / สวน-คาเฟ่) → ให้ผู้เล่น 8–15 คนเลือก

### Phase 1 — MVP บน staging
กลุ่ม playtest เล่น 1–2 สัปดาห์ · เก็บแบบสอบถามสั้นตอนจบห้อง

### Metrics ที่ต้องดู
| Metric | เทียบกับ |
|---|---|
| D1 / D7 retention | ผู้เล่นที่ไม่ได้เข้าโหมดนี้ |
| เกมต่อวันต่อคน | ก่อน vs หลัง |
| สัดส่วนระดับที่เลือก | ถ้า easy > 60% → ถ่างดาว |
| เวลาจบห้องแรก (median) | เป้า 3–5 วัน |
| % คนที่ทำงานแรกเสร็จ | onboarding ใช้ได้ไหม |
